# Leadership card fonts

Five open-source display fonts, stored in the repository and served by the app itself (`next/font/local`). Nothing is fetched from a font service at build or run time. Each font is licensed under the SIL Open Font License 1.1; the licence text for each is next to it (`OFL-*.txt`).

| Preset | Font | Source |
|---|---|---|
| Elegant Calligraphy | Pinyon Script | https://github.com/google/fonts/tree/main/ofl/pinyonscript |
| Luxury Signature | Mrs Saint Delafield | https://github.com/google/fonts/tree/main/ofl/mrssaintdelafield |
| Futuristic Display | Orbitron (variable) | https://github.com/google/fonts/tree/main/ofl/orbitron |
| Editorial Serif | DM Serif Display | https://github.com/google/fonts/tree/main/ofl/dmserifdisplay |
| Matrix Typography | Share Tech Mono | https://github.com/google/fonts/tree/main/ofl/sharetechmono |
